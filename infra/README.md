# Optional Research Infrastructure

This directory contains pinned launch/configuration material for tools that can improve engineering throughput or authorized data ingestion but must not become hidden dependencies of the SPX / Market Gravity Engine.

- `context-mode/`: coding-agent context management only.
- `ripwire/`: deterministic repository map, call-graph, blast-radius and test-impact assistance for code changes only.
- `camofox/`: isolated authorized browser ingestion only.

None of these tools may modify canonical Stage 1/2/3 outputs, become a hidden market-data source, or place trades.
